## Hướng dẫn khởi chạy nhanh (Case Study 2)
1. **Backend (`api/`):** Tạo file `api/.env` từ `api/.env.example`, chạy `npm run dev` (hoặc `npm --prefix api start`) ở thư mục gốc để mở API Server tại `http://localhost:3000`.
2. **Frontend (`TaskManager/`):** Chạy `flutter pub get` và `flutter run` trong thư mục `TaskManager` (hoặc mở nhanh trên Windows bằng `run_project.bat`).
